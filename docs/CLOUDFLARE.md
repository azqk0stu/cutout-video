# Cloudflare Pagesへの公開

## ZIPで公開する（Gitへのプッシュ不要）

1. Cloudflareダッシュボードにログインします。
2. Workers & PagesからPagesプロジェクトを作成し、静的ファイルの直接アップロードを選択します（画面上の名前は変わることがあります）。
3. 準備済みの `campus-voice-cloudflare.zip` をアップロードします。ZIP内の直下には `index.html`・`app.js`・`model.js`・`style.css`・`_headers` が入っています。
4. デプロイ後にCloudflareが表示するURLを開き、JSON読み込み欄が表示されることを確認します。
5. Colabで生成した解析JSONと元音声を読み込み、編集します。「作業全体を保存」は再編集用、「Colab用の編集JSONを保存」は動画生成用です。

ZIPの再生成: `python scripts/package_cloudflare.py`

この静的サイトに音声・解析結果・秘密情報をアップロードする必要はありません。編集画面のファイル選択はPC内で処理されます。作業を保存せずページを閉じると編集内容は失われます。

## Git連携を選ぶ場合

ソースをGitHubにプッシュした後、Cloudflare Pagesで対象リポジトリを接続します。フレームワーク「なし」、ビルドコマンドは空欄、出力ディレクトリは `web`。自動更新を使いたい場合はこちらが便利です。

この作業時点ではCloudflare CLIは未認証であり、公開は実行していません。トークンをチャットに貼る必要はありません。ダッシュボードからのアップロードなら、この実行環境への認証情報の設定は不要です。
