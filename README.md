# Campus Voice

個人用ラジオ切り抜きツールの初版。静的編集画面をCloudflare Pagesへ、音声処理をGoogle Colabへ分離します。常時稼働するバックエンド・APIキー・データベースは不要です。

## 最初の確認（Cloudflare公開前でも可能）

1. `notebooks/campus_voice.ipynb` をダウンロードし、Google Colabの「ファイル → ノートブックをアップロード」で開きます。
2. GPUランタイムを選び、依存関係のインストール、編集画面のダウンロード、元音声のアップロード、文字起こしまで順に実行します。初回は冒頭3分のみ解析します。
3. ダウンロードされた `campus-voice-editor.html` をPCのブラウザで開きます。`analysis.json` と元のMP3を読み込み、30〜60秒の範囲を選んで編集JSONを保存します。このHTMLはネット接続不要です。
4. Colabで編集JSONと任意のBGMを選び、動画生成セルを実行します。
5. 結果を確認したら `TEST_SECONDS = 0` で全編を解析します。その後、同じ編集画面をCloudflare Pagesで公開できます。

チャットに添付した音声はColabへ自動転送されません。元のMP3をPCから選択してください。32MBを超える添付ファイルは、このチャットの実行環境では取得できないため、実音声の解析はまだ未検証です。

## 使い方

1. `notebooks/campus_voice.ipynb` をGoogle Colabで開く。可能ならGPUランタイムを選び、インストールと元音声のアップロード、文字起こしセルを実行。
2. ダウンロードした `analysis.json` を編集画面で読み込み、試聴用に同じ元音声を選ぶ。
3. 候補の前後を聴いて、時刻・字幕・話者名・タイトルを編集。候補以外の範囲は開始・終了秒で指定可能。
4. 動画サイズとBGM音量を指定し、編集JSONを保存。
5. Colabの後半セルで編集JSONと任意のBGMをアップロードし、MP4を生成。2本目も別の範囲を選んで繰り返す。

元音声は編集画面から送信しません。解析結果もブラウザメモリ内のみです。「作業全体を保存」で解析結果・修正済み字幕・選択範囲・設定をJSONに保存し、後から同じ読み込み欄で再開できます。音声は別途選び直してください。Colabには音声が送信されます。手元の保存ファイルは個別に削除し、Colabのデータはランタイムを削除してください。音声とBGMの利用・再公開の許可は別途確認してください。

## ローカル開発

Node.js 24 / Python 3で `npm test`、`python -m unittest discover -s tests -p '*_test.py'`（FFmpegが必要）、`npm run dev`。静的ファイルは `web/`。編集画面を変更したら `python scripts/prepare_notebook.py` でノートブック内の単体版にも反映します。

## Cloudflare Pages

直接アップロード用ZIPを `python scripts/package_cloudflare.py` で生成できます。手順は [docs/CLOUDFLARE.md](docs/CLOUDFLARE.md) を参照してください。

Git連携でこのリポジトリを選び、フレームワークなし、ビルドコマンドなし、出力ディレクトリ `web` を指定します。Node互換フラグやサーバー、秘密情報は不要です。公開URLを知る人は編集画面にアクセスできます。個人用のアクセス制限が必要ならCloudflare Accessを設定してください。
CLIを使う場合はCloudflare認証後 `npm run deploy`（Wranglerを取得します）。この作業ではまだCloudflareへの公開はしていません。

## 現在の実装範囲と制限

- 日本語文字起こし、無音境界と発話密度による候補、試聴、範囲・字幕・話者欄の編集、JSON出力。
- 単色背景と字幕、任意のBGM（音量・フェード）、9:16 / 1:1 / 16:9のMP4生成。
- **話題の意味解析・自動話者分離・笑い声検出は未実装**。話者欄は手入力です。これらは今後の実装対象です。
- タイトルは編集データに保存しますが、動画への表示は未実装です。背景画像の選択も今後追加します。
- Colabとの連携はファイル受け渡し。無料枠のGPU割り当て・処理完了・処理時間は保証されません。CPUへの切替は低速です。
- アップロードされた実音声の解析、Colab上での実行、Cloudflare本番配信は未検証です。
